## Contributing

Contributions are welcome through GitHub issues and pull requests.

- Keep changes focused, reviewable, and covered by the relevant tests.
- Run the Release build and regression suite before opening a pull request.
- Never submit vaults, PINs, keyfiles, recovery codes, TOTP secrets, private keys, signing certificates, personal audit data, or other credentials.
- Follow `SECURITY.md` for security-sensitive reports and avoid publishing exploitable details or secrets in a public issue.
- Add a short entry to this file when a contribution is merged, unless the contributor prefers not to be listed.
